# 问卷设计 v1（原创中文 33 题 + 反馈插页）

> 项目：better-me（全栈挑战）
> 本文档是 `lib/quiz/config.ts` 的**唯一依据**。与 `doc/题库采集-betterme.md`（竞品观察）**区分**——本文是原创题库，不是克隆。
> `quizVersion: "v1"`

## 类型化题目结构（Types）

每题一个变体：
- `single`：单选（选项即按钮）
- `multi`：多选（checkbox）
- `number`：数字输入（身高/体重等，含 min/max/单位）
- `likert`：李克特量表（1-5 同意度）

公共字段：`key`（唯一，stepKey 单源）、`type`、`question`、`required`、`options[]`（含逐项 `feedback`）、数字题含 `validation{min,max,unit}`。

## 题型构成（33 题）

| 分组 | 题数 | 说明 |
|---|---|---|
| 核心计算 | 7 | gender / age / goal / height / weight / target_weight / activity_frequency |
| 身体与历史 | 6 | 体型 / 梦想身材 / 体重变化 / 上次最佳身材 / 增重诱因(multi) / 额外目标(multi) |
| 运动与体能 | 8 | 日常活跃度 / 精力 / 步行频率 / 运动频率 / 可运动时间 / 期望频率 / 偏好时段(multi) / 运动舒适度 |
| 健康与限制 | 5 | 呼吸急促 / 运动不适部位(multi) / 睡眠 / 压力 / 既往伤病史(multi) |
| 营养与情绪 | 7 | 营养习惯 / 渴望食物(multi) / 三餐规划 / 饮食类型 / 断食了解 / 餐数 / 情绪化进食(likert) |

合计 = 7+6+8+5+7 = **33 题**。

## 每题的 key / 题目 / 选项 / 反馈要点

### 核心计算（7）
1. **gender** (single) 你的性别 → `male`/`female`；反馈如「收到，我们会按你的性别校准参数。」
2. **age** (single) 你的年龄 → `18-29`/`30-39`/`40-49`/`50+`；反馈因档位略不同。**计算用年龄取档位中位岁数**（`AGE_RANGE_MIDPOINT`：24/35/45/57，常量单源，BMR 公式引用）。
3. **goal** (single) 你的主要目标 → `lose_weight`/`maintain`/`gain_weight`（增重/增肌，供偏瘦用户）；反馈不同。**目标体重合理性由服务端按 goal 分支校验**：lose_weight → target ≤ weight；gain_weight → target ≥ weight；maintain → 允许接近（不做写死的 compareTo，避免增重用户被拒）。
4. **height** (number) 你的身高(cm) → min 100 max 250 单位 cm；反馈按区间（<150/150-180/>180）。
5. **weight** (number) 你的体重(kg) → min 30 max 250 单位 kg；反馈按 BMI 倾向。
6. **target_weight** (number) 你的目标体重(kg) → min 30 max 250；跨字段校验见 goal。
7. **activity_frequency** (single) 你每周平均运动几次 → `sedentary`/`light`/`moderate`/`active`；反馈不同。

### 身体与历史（6）
8. **physical_build** (single) 你的体型 → `slim`/`mid`/`full`/`extended`。
9. **dream_body** (single) 你理想的体态 → `thin`/`toned`/`curvy`/`average`。
10. **weight_change** (single) 你的体重通常怎么变化 → `gain_fast_lose_slow`/`gain_lose_easy`/`struggle_gain`。
11. **best_shape_ago** (single) 上次最佳身材距今 → `<1y`/`1-2y`/`>3y`/`never`。
12. **weight_gain_causes** (multi) 近年哪些事导致体重变化 → 工作压力/家庭/代谢放缓/经济/疫情/其他/None（None 互斥）。
13. **other_goals** (multi) 你还希望达成 → 增肌/改善体态/减压/灵活/None（None 互斥）。

### 运动与体能（8）
14. **daily_activity** (single) 日常大多久坐/活动 → `sedentary`/`light`/`active`。
15. **energy_levels** (single) 白天精力 → `low`/`average`/`high`。
16. **walk_freq** (single) 步行频率 → `daily`/`few`/`rare`。
17. **exercise_freq** (single) 运动频率 → `daily`/`few_week`/`rare`。
18. **exercise_time** (single) 每次可运动时长 → `10-20`/`20-40`/`40+`。
19. **desired_freq** (single) 期望每周运动次数 → `1-3`/`3-5`/`5+`。
20. **preferred_time** (multi) 偏好时段 → 早晨/中午/下午/晚上（可多选）。
21. **workout_comfort** (single) 运动中是否不适 → `yes`/`no`/`sometimes`。

### 健康与限制（5）
22. **shortness_breath** (single) 呼吸急促频率 → `often`/`sometimes`/`never`。
23. **discomfort_areas** (multi) 哪些部位不适 → 膝/腰背/肩颈/关节/None。
24. **sleep_quality** (single) 睡眠质量 → `good`/`fair`/`poor`。
25. **stress_level** (single) 压力水平 → `low`/`moderate`/`high`。
26. **injury_history** (multi) 既往伤病 → 膝/腰/肩/无/其他（None 互斥）。

### 营养与情绪（7）
27. **nutrition_habit** (single) 饮食习惯 → `healthy`/`okay`/`needs_work`。
28. **food_cravings** (multi) 最渴望的食物 → 甜食/碳水/咸味/油炸/None。
29. **meal_planning** (single) 如何规划三餐 → `planned`/`spontaneous`/`skip`。
30. **diet_type** (single) 偏好的饮食方式 → `traditional`/`keto`/`vegan`/`intermittent`。
31. **fasting_knowledge** (single) 对间歇断食了解 → `none`/`some`/`expert`。
32. **meals_per_day** (single) 每天几餐 → `<3`/`3`/`>3`。
33. **emotional_eating** (likert) 我常在压力/情绪下进食(1-5 同意度) → 1..5。

## 反馈插页（7-9 个，不计入 33 题，非数据库答案）

穿插在题目集群之间，制造节奏、不连续表单。类型：
- **个性化回应**：复述用户刚才的选择 + 鼓励（如「增重慢的人我们最擅长处理」）。
- **进度里程碑**：「已完成 X / 33」+ 节点鼓励。
- **社交证明（通用措辞，不虚构数字）**：如「很多人都和你一样，从这一步开始改变」。
- **算法预览**：「再补几个问题，就能算出你的 BMI 和热量需求」。
- **计算/加载态**：提交后展示「正在为你计算专属方案…」。

> 这些是**反馈模块**，不写入 `assessment_answer`，只是前端节奏层。

## 结构测试要求（`lib/quiz/config.test.ts`）

断言：
1. 恰好 **33** 题（不含插页）。
2. 所有 `key` 唯一。
3. 每个可选项都有**非空** `feedback`（兜底"忘配文案"）。
4. 数字题有 `min/max/unit`。
5. 必填的计算 key（gender/age/height/weight/target_weight/activity_frequency/goal）都在。
6. `multi` 题含 `none` 选项时，`none` 与其它选项**互斥**（选 none 不能再选其它）。
7. `quizVersion` 存在。
